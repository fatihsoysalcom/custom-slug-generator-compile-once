# Custom Slug Generator Compile Once

This example demonstrates the 'compile once' philosophy by providing a self-contained Python script for generating URL-friendly slugs. Instead of relying on external services or libraries for a common utility task, you build and own the solution once, ensuring long-term reusability and avoiding recurring costs. It highlights how investing in a custom, single-purpose tool can be more efficient than continuous external dependencies.

## Language

`python`

## How to Run

Save the code as `slug_generator.py`. Run from your terminal: `python slug_generator.py`
